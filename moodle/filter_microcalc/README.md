# MicroCalc для Moodle 4.1+

Фильтр заменяет `{microcalc id=318}` в любом тексте (страница, лекция, тест, форум) на калькулятор или тренажёр MicroCalc.

1. Администрирование → Плагины → Установить плагины → загрузить `filter_microcalc-<версия>.zip` из [Releases](https://github.com/WasiliyMalyshev/microcalc.io-plugins/releases). Вручную: папку `microcalc` из архива положить в `filter/`.
2. Администрирование → Плагины → Фильтры → Управление фильтрами: включить «Виджеты MicroCalc».
3. В настройках фильтра принять условия, при желании выбрать язык, тему и цвет кнопок.
4. В тексте: `{microcalc id=318}`, можно `lang`, `theme`, `accent`, `width` и другие параметры из `spec/embed.md`.

Подсказки о причинах (условия не приняты, калькулятор не найден) видят только преподаватели, студенты не видят ничего.
